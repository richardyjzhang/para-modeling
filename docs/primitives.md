# 内置图元约定

> 本文是各图元**几何含义**的权威说明：有哪些 `dims` 参数、局部坐标系怎么摆、与 Three.js 默认几何差在哪。
> 字段名 / 枚举拼写以 [`conventions.md`](conventions.md) 为准，本文不重复登记拼写。
> 实现必须遵守本文；若实现需要偏离，先改本文再动代码。

所有 `dims` 值均为**表达式字符串**（常数也写成 `"200"`）。单位毫米。每个图元有独立的局部坐标系，再经节点 / 零件的 `transform` 摆到父级坐标系。

---

## 通用约定

- **原点**：除非某节另有说明，原点在几何中心（不是底面中心）。
- **轴向**：工程世界与图元局部系都是右手系、Z 向上。圆柱 / 圆台的「高度轴」是局部 **Z**，不是 Three.js 默认的 Y。
- **渲染修正**：Three.js 部分几何体默认沿 Y。工厂在 `frontend/src/core/geometry.ts` 里对网格做一次旋转，使顶点落在本文规定的局部系里。调用方按局部系写 `transform` 即可，不必再补这层修正。
- **尺寸约束**：除圆台 `radiusTop` 允许 `0` 外，所有尺寸求值后必须 **> 0**。

## box（长方体）

对应 PDMS 的 BOX。第 3 期已实现。

### 参数

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `x` | 沿局部 X 的边长 | > 0 |
| `y` | 沿局部 Y 的边长 | > 0 |
| `z` | 沿局部 Z 的边长 | > 0 |

### 局部坐标系

原点在长方体中心。六面分别垂直于局部 X/Y/Z，范围 `[-x/2, x/2]` × `[-y/2, y/2]` × `[-z/2, z/2]`。

```
        Z（高）
        ^
        |
        +--------+
       /        /|
      /        / |
     +--------+  +
     |        | /
     |        |/ ----> Y（宽）
     +--------+
    /
   X（长）
```

### 渲染修正

Three.js `BoxGeometry(x, y, z)` 的三条边本来就沿局部 X/Y/Z，且中心在原点。**无需旋转**。

## cylinder（圆柱）

对应 PDMS 的 CYLI。第 3 期已实现。

### 参数

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `radius` | 底面圆半径 | > 0 |
| `height` | 沿轴向的高度 | > 0 |

### 局部坐标系

原点在圆柱中心。轴线沿局部 **Z**，从 `z = -height/2` 到 `z = +height/2`。两个端面是垂直于 Z 的圆。

```
        Z（轴）
        ^
        |  ___
        | /   \
        ||     |
        ||     |
        ||     |
        | \___/
        +--------> Y
       /
      X
```

### 渲染修正

Three.js `CylinderGeometry(radiusTop, radiusBottom, height)` 默认轴线沿 **Y**。构建后对几何 `rotateX(π/2)`：原 +Y 端面转到 +Z。这样轴线落到局部 Z，中心仍在原点。

## cone（圆台 / 圆锥）

对应 PDMS 的 SNOU。第 4 期已实现。

### 参数

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `radiusBottom` | 局部 Z 负端（底）的圆半径 | > 0 |
| `radiusTop` | 局部 Z 正端（顶）的圆半径 | ≥ 0（`0` 即圆锥） |
| `height` | 沿轴向的高度 | > 0 |

### 局部坐标系

原点在高度中点（不是底面中心）。轴线沿局部 **Z**。`radiusBottom` 在 `z = -height/2`，`radiusTop` 在 `z = +height/2`。侧面是直线母线。

### 渲染修正

用 `CylinderGeometry(radiusTop, radiusBottom, height)`（注意 Three.js 第一个参数是顶半径），再 `rotateX(π/2)`，与圆柱同一套修正。修正后：Three.js 的「顶」（原 +Y）落到局部 +Z，对应本约定的 `radiusTop`。

## sphere（球）

第 4 期已实现。

### 参数

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `radius` | 球半径 | > 0 |

### 局部坐标系

原点在球心。各向均匀，无特殊轴向。

### 渲染修正

Three.js `SphereGeometry(radius)` 中心已在原点。**无需旋转**。

## torus（圆环）

对应 PDMS 的 CTOR。第 4 期已实现。

### 参数

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `radius` | 环中心线半径（从原点到圆管中心线） | > 0 |
| `tubeRadius` | 圆管截面半径 | > 0，且通常 `< radius`（自交与否本期不强制） |

### 局部坐标系

原点在圆环整体中心。环面（圆管中心线所在平面）是局部 **XY**，圆环的「洞」沿局部 **Z**。

```
        Z（洞的轴向）
        ^
        |
        |    ____
        |   /    \
        |  |  .   |   ← 管截面圆心距原点 = radius
        |   \____/
        +--------> Y
       /
      X     环面在 XY
```

### 渲染修正

Three.js `TorusGeometry(radius, tube)` 默认环面就在 XY、洞沿 Z。与本约定一致，**无需旋转**。
