# 🏗️ para-modeling

> 一个跑在浏览器里的**参数化建模工具** —— 定义一次元件，改改参数，处处复用。

面向桥梁、房建等工程场景：把常用构件做成"参数化元件"存进库里，搭建场景时选型、填参、摆放，模型立即成形。改一个参数，形状实时更新。✨

## 🌟 它能做什么

### 🧱 像搭积木一样建模

- 内置长方体、圆柱、圆台、球、圆环等基础几何体，拖进场景直接摆
- 层级树管理整个工程：场地 → 分区 → 构件，井井有条
- 点树亮模型、点模型亮树，选中、移动、旋转、复制一气呵成

### 📦 自己的元件库

- **元件编辑器**：用基础几何体拼出你的构件——桥墩、主梁、门窗、栏杆……
- 元件存进分类库，随取随用，一个团队共享一套积木
- 元件库可打包导出 📤 / 导入 📥，成果轻松分享

### 🎛️ 参数驱动，一件顶一百件

- 给元件定义参数（长度、半径、高度……），尺寸用**表达式**描述：
`sqrt(W^2 + H^2) / 2`、`sin(angle) * R` 都不在话下 🧮
- 实例化时填参数：同一个"桥墩"模板，摆出 8 米、12 米、15 米三种墩
- 拖动参数，3D 预览实时变形，所见即所得

### 🍱 元件套元件

- 元件可以引用其他元件：做好"门把手"，再拼出带把手的"门"
- 改了门把手，所有用它的门自动跟着变 🔄
- 你也可以只拿门把手，去做自己的门



### 🌉 面向工程的几何能力

- **拉伸体**：工字钢、T 梁截面，一个轮廓拉出来
- **旋转体**：圆管、封头，一条母线转出来
- **扫掠体**：弯桥主梁沿曲线一扫成型，还支持变截面
- **连接点对齐**：元件自带连接点，构件之间精确拼接 🧲
